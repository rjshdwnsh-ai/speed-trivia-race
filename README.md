# Speed Trivia Race — Netlify-ready

This is a small real-time-by-polling multiplayer game for 2–8 players. Players use a room code from separate devices; the frontend polls a Netlify Function every 1.2 seconds, and the function stores shared room state in Netlify Blobs with strong consistency and ETag-based conditional writes.

## Publish using Netlify Drop
1. Upload this ZIP to Netlify Drop: https://app.netlify.com/drop
2. Netlify should build the project using the root `netlify.toml` and `package.json`.
3. When deployment finishes, open the generated public URL in two devices or a normal and private browser window.
4. Create a room in the first window, share the room code, join from the second, and start the game.
5. Verify both players see the same questions, timer, scores, and final winner.

## Rules
- 2–8 players per room.
- This quick-match edition has 3 rounds, each with a 15-second timer.
- Correct answer: 100 points plus a speed bonus of up to 50 points.
- Incorrect, late, or unanswered: 0 points.
- One answer per player per round; server validates answers and scoring.
- The room host starts the game.
- A player cannot join after a game has started. If a player disconnects, their room entry remains, but the host may need to create a fresh room for a clean match.

## Technical notes
- Frontend calls `/.netlify/functions/game` directly.
- Room reads request strong consistency. Writes use `onlyIfNew` for room creation and `onlyIfMatch` with the current ETag for updates, retrying conflicts.
- Netlify Blobs conditional writes are not multi-key transactions. This implementation stores each room as one blob and uses compare-and-swap for room updates.
- This package has not been deployed to a Netlify account from this environment. After publishing, test it on the public URL before submitting.
- The root package lock should be generated by the build platform from `package.json` if absent; if Netlify requires a lockfile for your chosen build settings, run `npm install` locally and include the generated `package-lock.json`.
